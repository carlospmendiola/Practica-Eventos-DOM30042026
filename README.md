Resumen de las tareas realizadas para la creación del ejercicio de Práctica de Eventos

## Descripción
Web App que permite filtrar imágenes por categorías generadas dinámicamente a partir de un array de objetos. Se generan también dinámiv¡camente el alt de las imágens y los títulos de la imagen principal y de las imágenes secundarias

## Funcionalidades
Se han generado dinámicamente los botones a partir de las etiquetas del array de imágenes
Mediante el objeto Set se han elimindo las etiquetas duplicadas
Al hacer click en los botones se mostraban las diferentes imágenes asociadas a esa etiqueta o categoría
Además de mostrar las imágenes indicamos el número y la categoría destacadamente
Diferenciación a la hora de visualizar las imágenes, la primera encontrada en grande, con su título encima y centrado como un H3 y el resto de imágenes si hay en la categoría, más pequeñas y debajo mostrando el H4 del título de la imagen
Cuando hacemos click en la imagen secuandaria esta se cambia por la principal mostrando también su título en H3
